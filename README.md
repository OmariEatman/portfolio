# Omari Eatman — portfolio

A responsive, five-page personal portfolio built with plain HTML, CSS, and JavaScript.

Open `index.html` in a browser. No installation or build step is required.

## Pages

- Home: `index.html`
- About Me: `about.html`
- Projects: `projects.html`
- Skills: `skills.html`
- Contact: `contact.html`

Shared styles live in `css/styles.css`, navigation behavior in `js/main.js`, and project placeholder illustrations in `images/`.

## Add your content

Replace the labeled biography, education, interest, skill, and contact placeholders with accurate details. Replace all three project entries and SVG placeholders with real project descriptions and screenshots; add demo or source links where applicable. No project or proficiency is claimed by the placeholder content.

The Contact page currently displays an email placeholder, with no form or sending functionality. Once an email address is supplied, add a `mailto:` link.

See `AGENTS.md` for design, implementation, and Git guidance.
